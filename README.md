# Portfolio — Purna Sainath Reddy V

Personal developer portfolio built with Next.js (App Router), TypeScript, Tailwind CSS v4, shadcn/ui, and Motion.

See `BUILD_PLAN.md` for the design/build strategy, `PROGRESS.md` for the live build checklist, `FUTURE_PLANS.md` for deferred ideas, and `CHAT_LOG.md` for the build conversation history.

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```
